File Content and Format 
 
Each data file is a FITS binary table.  The primary FITS header contains the following 
information: 
 
FITS File primary header 
 
 
 
 
 
 
 
OFFSETPX gives the offset of the target in pixels (0.05 arcsecond) from the center of 
the slit as measured using the G750L fringe flats (Section 3.2).  DATAQUAL is used to 
flag data that may be suspect because of a large centering error within the slit.  The data 
are flagged as suspect if the offset error is more than 0.9 pixels.  Mis-centering greater 
than 0.9 pixels result in large errors in the aperture throughput correction. 
 
The file’s binary table extension contains three columns:
